# CloutDesk (CloutJam)

> The agent-first, AI-native platform for modern influencer marketing and creator management. CloutDesk (formerly CloutJam; 500 Global-backed, NYC) is building open infrastructure for creator marketing — outreach, relationship management, content approval, contract negotiation, invoicing, reporting, and payments — with every workflow exposed to AI agents through MCP, a REST API, and a CLI. The developer platform is in Beta.

## Agent-native surfaces (Beta — Apply for Beta)
- MCP server: `npx @cloutdesk/mcp` — stdio and Streamable HTTP transports; OAuth login; Claude Desktop / Claude.ai / Claude Managed Agents / Cursor (package not yet published on npm as of 2026-07-18)
- REST API: v1, cursor-paginated, RFC 7807 errors, idempotent writes (Idempotency-Key), OpenAPI 3.1 (spec not yet published); Bearer Personal Access Tokens (`cd_pat_`) and OAuth for org installs
- CLI: `cloutdesk` (npm) — wraps the REST API for scripted workflows and CI (package not yet published on npm as of 2026-07-18)
- Webhooks + realtime
